# ГИС «Господдержка»: Модуль автоматизированного распределения мер поддержки

## 1. Общие сведения о проекте
Система предназначена для автоматизации процессов приема, юридической и финансовой проверки, а также рассмотрения заявок промышленных предприятий на получение субсидий и льготного финансирования Минпромторга РФ.

* **Заказчик:** Министерство промышленности и торговли РФ (Минпромторг).
* **Целевая аудитория:** Промышленные предприятия (заявители), сотрудники департаментов Минпромторга (операторы).
* **Ключевая метрика (KPI):** Сокращение среднего срока обработки заявки с 14 рабочих дней до 2 часов за счет интеграции с автоматическими реестрами и AI-скорингом.

---

## 2. Ролевая модель (Акторы)

| Роль | Тип | Описание и зоны ответственности |
| :--- | :--- | :--- |
| **Заявитель** | Внешний пользователь | Представитель промышленного предприятия. Подает заявку, отслеживает статус, подписывает итоговый договор в ЛК. |
| **Оператор Минпромторга** | Внутренний пользователь | Сотрудник ведомства. Рассматривает агрегированное заключение системы и утверждает/отклоняет предоставление поддержки. |
| **Система (Backend Orchestrator)** | Системный актор | Оркестрирует межсистемные запросы, выполняет бизнес-правила, формирует аналитическое заключение. |
| **Внешний сервис ФНС / ЕГРЮЛ** | Внешняя система | Предоставляет данные о статусе юрлица, выручке, наличии налоговых задолженностей. |
| **Внешний сервис Федресурс** | Внешняя система | Предоставляет сведения о процедурах банкротства и существующих обременениях. |
| **Модуль AI-скоринга** | Внутренний/Смежный сервис | Рассчитывает финансовый рейтинг компании и вероятность целевого использования средств. |

## 3. Архитектурный контекст экосистемы

Система распределения поддержки является первым звёновым модулем в едином цифровом контуре государственной поддержки промышленности:

```mermaid
graph TD
    classDef primary fill:#e1f5fe,stroke:#0288d1,stroke-width:2px;
    classDef secondary fill:#f3e5f5,stroke:#7b1fa2,stroke-width:1px;

    subgraph M1 ["МОДУЛЬ 1 (Текущий проект)"]
        A["<b>Автоматизация распределения господдержки</b><br/>Подача заявки ➔ AI-скоринг ➔ Принятие решения"]:::primary
    end

    subgraph M2 ["МОДУЛЬ 2 (Проект Участницы 2)"]
        B["<b>Мониторинг исполнения проектов</b><br/>Контроль сроков, бюджета и этапов модернизации"]:::secondary
    end

    subgraph M3 ["МОДУЛЬ 3 (Проект Участницы 3)"]
        C["<b>Формирование и проверка отчётности</b><br/>Контроль целевого использования выделенных средств"]:::secondary
    end

    A -->|"При одобрении заявки<br/>(передача параметров проекта)"| B
    B -->|"При наступлении отчётного периода<br/>(график выплат и контрольные точки)"| C

* **Передача данных в Модуль 2:** При принятии решения «Одобрено» карточка одобренного проекта, параметры финансирования и График реализации транслируются в *Систему мониторинга проектов*.
* **Передача данных в Модуль 3:** Финансовые условия (суммы, статьи расходов) передаются в *Систему контроля отчётности* для автоматической сшивки с входящими первичными документами.
