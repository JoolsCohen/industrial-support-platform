
# Платформа государственной поддержки промышленности

**Учебный проект по системному анализу**

## О проекте

Проектирование информационной системы для автоматизации приёма, проверки и рассмотрения заявок промышленных предприятий на получение мер государственной
поддержки. Система должна обеспечивать централизованную обработку заявок, автоматизацию проверок по заданным правилам, подготовку результатов оценки и поддержку принятия решений
уполномоченными сотрудниками.

## Цель проекта

Спроектировать систему автоматизации приёма, проверки и рассмотрения заявок промышленных предприятий на получение мер государственной поддержки.

## Основные задачи

- Описать бизнес-процесс обработки заявок.
- Определить заинтересованные стороны и их полномочия.
- Сформулировать бизнес-правила.
- Разработать функциональные и нефункциональные требования.
- Спроектировать модель данных.
- Описать интеграции с внешними источниками данных.
- Разработать спецификацию API.
- Подготовить тестовые сценарии и критерии приёмки.

## Технологические артефакты

В рамках проекта планируется подготовить:

- Диаграммы BPMN 2.0, UML и ERD.
- Спецификацию API в формате OpenAPI.
- Примеры запросов и ответов в JSON.
- SQL-схему базы данных.
- Тестовые сценарии.

## Ограничения

Проект является учебным кейсом по системному анализу. Внешние интеграции моделируются с использованием тестовых данных. Реальное подключение к государственным системам и перечисление денежных средств не предусматриваются.
