# ГИС «Господдержка» — маркетинговая веб-страница

Это адаптивная одностраничная страница с прокруткой, в тёмной палитре исходной презентации. Она предназначена для представления концепции проекта в портфолио, а не заменяет защитную презентацию.

## Состав

- `index.html` — сайт (HTML, CSS и JS без внешних библиотек и сборки).
- `Defense_Presentation_Gospodderzhka.pdf` — PDF-презентация.
- `Defense_Presentation_Gospodderzhka.pptx` — исходный PowerPoint.

## Локальный просмотр

Откройте `index.html` в браузере или воспользуйтесь расширением Live Server в VS Code.

## Публикация через GitHub Pages

1. Скопируйте содержимое этой папки в `presentation-site/` своего репозитория.
2. Сделайте commit и push через VS Code.
3. В GitHub откройте **Settings → Pages** и выберите **Deploy from a branch**, ветку `main`, папку `/(root)`.
4. После публикации откройте `https://USERNAME.github.io/REPOSITORY/presentation-site/`.

Все ссылки на файлы относительные, поэтому страница поддерживает публикацию в подпапке репозитория.

## Важно

KPI, скоринговые пороги и стоп-факторы на странице обозначены как проектные допущения учебной концепции. Они не являются измеренными результатами или универсальными нормативными требованиями. Внешние интеграции представлены mock-сценариями.
